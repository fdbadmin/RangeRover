1) Introduction

RangeRover is a probabilistic volumetric screener for hydrocarbon resources. It runs Monte Carlo simulations using user‑defined distributions for key volumetric inputs, producing CDFs, histograms, tornado sensitivity charts, and CSV exports.

The tool supports five fluid types — Oil, Gas, Coal Seam Gas, Oil + Solution Gas, and Gas + Vaporized Oil — with an optional Advanced Mode for multi‑reservoir analysis, inter‑parameter correlations, shared parameters across reservoirs, and inter‑reservoir dependencies.

2) Quick Start

Basic Mode

  1. Select a Fluid type — the parameter list, formula, and units update automatically.
  2. Choose units for Area and Thickness (or switch to GRV geometry mode).
  3. For each parameter, pick a Distribution type and enter its values. Labels above each input box tell you what to enter (e.g., Mean / Std Dev for Normal, or Min / Mode / Max for Triangular).
  4. Set the Recovery Factor distribution.
  5. Press Run Simulation.

Advanced Mode

  1. Toggle Advanced Mode on (top of the left panel).
  2. Reservoir tabs appear — use + Add to create additional reservoirs (up to 5).
  3. Each reservoir has its own fluid type, parameter distributions, and recovery factor.
  4. Optionally define Parameter Correlations, Shared Parameters, and Inter‑Reservoir Correlations.
  5. Press Run Simulation to see individual and aggregated results.

3) Inputs & Units

  • Area: m², km², acres, or ft² (internally converted to acres).
  • Thickness: m or ft (internally converted to ft).
  • NTG, Porosity, Water Saturation: fractions (0–1). Previews display as % for readability.
  • Bo (RB/STB): Oil formation volume factor.
  • Bg (scf/SCF): Gas formation volume factor.
  • Rs (scf/bbl): Solution gas–oil ratio (Oil + Solution Gas fluid only).
  • Rv (bbl/scf): Vaporized oil–gas ratio (Gas + Vaporized Oil fluid only).
  • Coal Density (g/cm³): Typically 1.3–1.5 (Coal Seam Gas only).
  • Gas Content (m³/ton): Gas adsorbed per ton of coal (Coal Seam Gas only).
  • Recovery Factor: fraction (0–1). Multiplies in‑place volumes to give recoverable volumes.

4) Geometry Modes

RangeRover supports two geometry modes, selectable via the Geometry dropdown in Simulation Settings:

  • Area × Thickness (default): separate distributions for Area and Thickness. These are multiplied together in the volumetric formula.
  • GRV (Gross Rock Volume): a single GRV parameter replaces both Area and Thickness. Supported GRV units: 10⁶ acre‑ft, 10⁹ ft³, or 10⁶ m³ (internally converted to acre‑ft).

5) Distributions

Six distribution types are available for each parameter:

  • Normal (default): Enter Mean and Std Dev. The third field is ignored. Draws are truncated to physical bounds (accept–reject sampling).
  • Triangular: Enter Min, Mode, Max. Requires Min ≤ Mode ≤ Max.
  • PERT (Beta‑PERT, λ = 4): Enter Min, Mode, Max. Smoother alternative to Triangular. Implied mean = (Min + 4×Mode + Max) / 6. Truncated to physical bounds.
  • Uniform: Enter Min and Max. The middle field is ignored. All values in [Min, Max] are equally likely.
  • Known Distribution: Enter P90, P50, P10. Internally converted to a Normal fit: mean = P50, σ estimated from the P90–P10 spread.
  • Discrete: Enter 1, 2, or 3 distinct values with optional weight percentages. If weights are blank, they auto‑balance (e.g., 50/50 for two values, ~33/33/34 for three). Provided weights are normalised automatically.

6) Physical Truncation

All random draws are constrained to physically sensible ranges via accept–reject sampling:

  • NTG, Porosity, Sw, RF: 0 to 1
  • Bo: ≥ 1.0
  • Bg, Rv, Rs: > 0
  • Area, Thickness, GRV: > 0
  • Coal Density: > 0.1
  • Gas Content: > 0

7) Monte Carlo Engine

For each iteration, every input is sampled independently (or jointly via correlations in Advanced Mode), then the volumetric formula is evaluated:

  • Oil (STOIIP): 7,758 × A × h × NTG × φ × (1 − Sw) / Bo → MMBO
  • Gas (GIIP): 43,560 × A × h × NTG × φ × (1 − Sw) / Bg → BCF
  • Coal Seam Gas (GIIP): 48,013 × A × h × ρcoal × Gc → BCF
  • Oil + Solution Gas: STOIIP and Solution Gas GIIP computed simultaneously (see Dual‑Phase section).
  • Gas + Vaporized Oil: GIIP and Vaporized Oil computed simultaneously (see Dual‑Phase section).

Recoverable volume = In‑place × RF. P10 / P50 / P90 are computed from the empirical CDF. The deterministic mid‑case uses the most likely input value for each parameter: Normal → mean; Triangular / PERT → mode; Uniform → midpoint; Known → P50; Discrete → highest‑weighted value.

Seeded RNG: Supply a seed value for reproducible results. Uses the Mulberry32 algorithm. Leave blank for a random seed each run.

8) Outputs

  • CDF Plots (in‑place & recoverable): Cumulative distribution curves with red markers at P90 / P50 / P10 and a purple diamond for the deterministic mid‑case.
  • Histograms (in‑place & recoverable): Frequency distributions with vertical markers at P90 / P50 / P10 and deterministic mid‑case.
  • Tornado Chart: Sensitivity of each input parameter (see Tornado section).
  • Summary Table: P90 / P50 / P10 for in‑place and recoverable, plus the deterministic mid‑case and its equivalent P‑value (e.g., “P45”).
  • Plot zoom syncing: All four plots share synchronised zoom/pan. Use the Reset buttons to restore the default view.

9) Dual‑Phase Fluids

When Oil + Solution Gas or Gas + Vaporized Oil is selected, a Results Metric dropdown appears:

  • Oil + Solution Gas:
    • STOIIP (MMBO): 7,758 × A × h × NTG × φ × (1 − Sw) / Bo
    • GIIP (BCF): 7,758 × A × h × NTG × φ × (1 − Sw) × Rs / Bo (÷ 1e9 → BCF)
    • Total (MMBOE): STOIIP + GIIP converted to BOE (BCF / 5.8 = MMBOE)
  • Gas + Vaporized Oil:
    • GIIP (BCF): 43,560 × A × h × NTG × φ × (1 − Sw) / Bg (÷ 1e9 → BCF)
    • Vaporized Oil (MMBO): 43,560 × A × h × NTG × φ × (1 − Sw) × Rv / Bg (÷ 1e6 → MMBO)
    • Total (MMBOE): GIIP as MMBOE + Vaporized Oil (MMBO)

The results table automatically shows a sub‑component breakdown: for example, Oil + Solution Gas “Total” shows STOIIP and Solution Gas as sub‑rows beneath the total, for both in‑place and recoverable volumes.

10) Tornado Sensitivity

The tornado chart shows the impact of varying each input parameter individually, while holding all others at their deterministic mid‑case values.

  • Low/High bounds are derived from each distribution: Normal = mean ± 1.28σ (≈ P10/P90); Triangular / PERT / Uniform = Min / Max; Known = P90 / P10; Discrete = min / max of the entered values.
  • Green bars = positive impact (upside); Red bars = negative impact (downside).
  • Parameters are sorted from largest impact (top) to smallest (bottom).
  • There is no limit to the number of variables shown.

11) Advanced Mode (Multi‑Reservoir)

Toggle Advanced Mode on to enable multi‑reservoir analysis.

  • Reservoir Tabs: Click tabs to switch between reservoirs. Each reservoir has independent fluid type, parameter distributions, recovery factor, and name.
  • Add / Remove: Use + Add to create up to 5 reservoirs. Click × on a tab to remove a reservoir (minimum 1).
  • Rename: Use the Reservoir Name field — the tab label updates automatically.
  • Results View: After running, switch between Total (All Reservoirs) to see aggregate P‑values, or select an individual reservoir to see its standalone results.
  • Multi‑Reservoir Summary Table: Shows P90 / P50 / P10 for each reservoir plus an aggregated Total row. For dual‑phase reservoirs, sub‑component rows are included. The total is computed by summing per‑iteration volumes across all reservoirs (after unit conversion to MMBOE), then taking P‑values of the summed distribution.

12) Parameter Correlations (Spearman ρ)

Define dependencies between parameters within the same reservoir using Spearman rank correlations.

  • The correlation matrix (under “Parameter Correlations”) shows all parameter pairs. Enter values from −1 (perfect inverse) to +1 (perfect positive). 0 = independent.
  • Presets: “None (Independent)” sets all to 0. “Typical Clastic” applies geologically common correlations (e.g., positive porosity–NTG, negative porosity–Sw).
  • Positive definite check: The matrix must be positive semi‑definite — a warning appears if it is not. Adjust values until the warning clears.
  • Engine: Correlations are enforced using the Iman‑Conover method with Cholesky decomposition, which rearranges the rank structure of independently drawn samples to match the target correlation matrix while preserving each parameter’s marginal distribution.

13) Shared Parameters

In Advanced Mode, downstream reservoirs (2nd, 3rd, etc.) can reuse the exact samples from an upstream reservoir for any matching parameter.

  • Under “Shared Parameters”, each parameter shows a dropdown: Independent (default) or Same as [Reservoir Name].
  • When shared, the downstream reservoir uses the same sample array drawn for that parameter in the source reservoir. This models situations where two reservoirs share the same geological property (e.g., same porosity across a shared formation).
  • The first reservoir cannot have shared links (it has no upstream source).
  • Shared parameters are applied before correlations, so shared samples still participate in the Iman‑Conover rank adjustment.

14) Inter‑Reservoir Correlations

Define dependencies between the same parameter across different reservoirs.

  • The table (under “Inter‑Reservoir Correlations”) has one row per parameter and one column per reservoir pair (e.g., R1 ↔ R2, R1 ↔ R3).
  • Enter Spearman ρ values from −1 to +1. Only parameters that exist in both reservoirs of a pair are available.
  • These correlations are combined with each reservoir’s intra‑parameter correlations into a single unified block correlation matrix, which is applied jointly using a single Iman‑Conover pass across all reservoirs.
  • Example: Setting Area correlation = 0.8 between R1 and R2 means when R1 draws a high Area, R2 is likely to as well — modelling geological proximity.

15) Distribution Previews

The Distribution Previews panel (collapsed by default) shows a mini PDF plot for each parameter, including the Recovery Factor. Previews update in real time as you change distribution types or values, and respect physical truncation bounds. Fractions are displayed as percentages for readability.

16) CSV Export

Two export buttons appear after a simulation run:

  • Summary CSV: P90, P50, P10, and deterministic mid‑case for in‑place and recoverable volumes.
  • Samples CSV: Every iteration with all input values (Area, Thickness/GRV, NTG, Porosity, Sw, Bo/Bg, RF, etc.) plus computed in‑place and recoverable volumes, with units in the header row.

17) Tips

  • Set a seed for reproducible results across runs.
  • Increase iterations (e.g., 50,000) for smoother CDFs, especially with multiple reservoirs.
  • Use PERT instead of Triangular when you know min/mode/max but want a smoother, less angular shape.
  • Use Normal (default) unless you have clear min/mode/max or P90/P50/P10 knowledge.
  • Use Known Distribution if you have P‑values from an external source — it fits a Normal internally.
  • Start with basic mode for a single reservoir, then switch to Advanced Mode to add more.
  • For dual‑phase fluids, run with Total (MMBOE) first to see the combined picture, then check individual components.
  • Click any collapsible section header to expand or collapse it — reduces clutter in the left panel.

18) Troubleshooting

  • Input errors: Error messages point to the first offending field (e.g., “Triangular min ≤ mode ≤ max”).
  • Blank plots: Check for missing numbers in required fields — fields labelled “(ignore)” can be left empty.
  • Correlation matrix not positive definite: Reduce extreme correlation values. A warning appears below the matrix — adjust until it clears.
  • Shared parameter greyed out: The source reservoir must have the same parameter (same fluid type and geometry mode).
  • Inter‑reservoir cell shows “—”: That parameter doesn’t exist in one of the two reservoirs in the pair.

19) Glossary

  • P10 / P50 / P90: High / median / low outcomes (probability of being exceeded: 90%, 50%, 10% respectively).
  • NTG: Net to Gross ratio. φ: Porosity. Sw: Water saturation.
  • Bo: Oil formation volume factor (RB/STB).
  • Bg: Gas formation volume factor (scf/SCF).
  • Rs: Solution gas–oil ratio (scf/bbl).
  • Rv: Vaporized oil–gas ratio (bbl/scf).
  • GRV: Gross Rock Volume — the product of Area × Thickness when entered directly.
  • STOIIP: Stock‑Tank Original Oil In Place (MMBO).
  • GIIP: Gas Initially In Place (BCF).
  • MMBOE: Millions of Barrels of Oil Equivalent (1 BCF ≈ 1/5.8 MMBOE).
  • PERT: Beta‑PERT distribution (λ = 4); smoother alternative to Triangular.
  • Iman‑Conover: Rank‑based method for imposing a target Spearman correlation structure on independently sampled distributions.
  • Spearman ρ: Rank correlation coefficient, −1 to +1. Measures monotonic (not necessarily linear) association.
  • Cholesky decomposition: Matrix factorisation used internally to apply the target correlation structure.
